# RoadRunner Frontend

Frontend application for the RoadRunner project built with React and Vite.

## Technologies

- React 19
- Vite
- ESLint

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## Development

The frontend uses React with Vite for fast development and hot module replacement (HMR).

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build locally

## Project Structure

- `src/` - Source code
- `public/` - Static assets
- `index.html` - Entry HTML file
